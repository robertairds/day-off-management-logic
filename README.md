# 📅 Project: Day Off Management

This project showcases my ability to structure data and manage complex workflows using logic and organization. **I designed and implemented this system during my previous experience in Human Resources**, where I was responsible for managing employee "Birthday Day Off" benefits, ensuring operational efficiency and clear data tracking.

## 🧠 The Logic Behind the Process
The challenge was to transition from a manual request process to a structured digital flow. I used **Excel** for data modeling and **Bisneo (HRMS)** for system execution.

### Key Logic Implemented:
- **Data Structuring:** Created a database in Excel to track eligibility based on hiring dates and birth months.
- **Conflict Management:** Applied logical filters to ensure that multiple employees from the same department wouldn't be absent simultaneously.
- **System Integration:** Migrated and managed this data within **Bisneo**, ensuring the digital records matched our operational rules.

## 🛠️ Tools & Methods
- **Excel:** Used for advanced filtering, data organization, and status tracking (Pending/Approved/Taken).
- **Bisneo (HRMS):** Managed the system's official records and employee requests.
- **Process Optimization:** Improved the organizational climate by creating a standardized and transparent digital request flow.

## 💡 Why this matters for Software Development?
Managing this project required **computational thinking**:
1. **Input/Output:** Managing how employee data (input) results in a scheduled day off (output).
2. **Business Rules:** Translating company policy into a logical sequence of steps for approval.
3. **Data Integrity:** Ensuring the Excel records were perfectly synced with the Bisneo HR system.
